# 🛒 React Shopping

یک پروژه فروشگاه ساده ساخته‌شده با **React + Vite** که امکان مرور و افزودن محصولات به سبد خرید را فراهم می‌کند.

![Vite](https://img.shields.io/badge/Vite-4-purple)
![License](https://img.shields.io/badge/License-MIT-green)

---

## 🚀 نصب و اجرا

```bash
# کلون کردن ریپو
git clone https://github.com/hossein020/React_shopping.git
cd React_shopping

# نصب وابستگی‌ها
npm install

# اجرای پروژه در حالت توسعه
npm run dev
# معمولاً در http://localhost:5173 باز می‌شود

# ساخت نسخه نهایی (production build)
npm run build

📂 ساختار پروژه
csharp
Copy code
vite-project/
├── public/              # فایل‌های استاتیک (تصاویر و غیره)
│   └── assets/          # تصاویر و اسکرین‌شات‌ها
├── src/
│   ├── components/      # کامپوننت‌های قابل استفاده مجدد
│   ├── pages/           # صفحات (مثل Products.jsx)
│   ├── App.jsx          # نقطه شروع اپلیکیشن
│   └── main.jsx         # ورود اصلی React
└── package.json
